# BowTieSecurityGuy website

Static one-page website for Rob Whetstine, prepared for bowtiesecurityguy.com and GitHub Pages. Layout adapted from Lindsey Yagi-Hatake’s website, with supplied purple/blue branding and images.

## Review

Open index.html locally. All images are in assets/. Booking inquiries currently use LinkedIn; no private account email is published. Speaking entries are discussion topics, not invented talk titles or workshop products.

## Publish with GitHub Pages

1. GitHub Pages on a private repository requires a supported paid plan. With GitHub Free, the owner must approve changing this repository to public. Do not change visibility without that approval.
2. In repository Settings > Pages, select Deploy from a branch, main, /(root), and save.
3. Set the custom domain to bowtiesecurityguy.com (also recorded in CNAME).
4. Configure Cloudflare DNS for GitHub Pages, replacing the former Porkbun website records once Pages is ready. Preserve unrelated mail/verification records. The www CNAME should target bowtiesecurityguy.github.io, not this repository’s URL.
5. Enable HTTPS once GitHub’s certificate is ready. Verify root and www in a private browsing window. Remove any remaining forwarding to YouTube.
